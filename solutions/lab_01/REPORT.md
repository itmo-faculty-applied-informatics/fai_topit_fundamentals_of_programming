В следующем коде напротив четырех сравнений записаны ожидаемые значения сравнения:

```Python
a = 1000
b = a

print("Типы:", type(a), type(b), type(c))
print("Идентификаторы:", id(a), id(b), id(c))
```

После запуска `task_2.py` результат полностью соответствовал ожиданиям.

Связь между именами и объектами можно представить в виде следующей схемы:


О равенстве значений говорят, когда 2 переменные ссылаются на объекты с одинаковым содержимым. А об идентичности говорят когда 2 переменные ссылаются на один объект в памяти.

Далее определение переменной `c` было изменено на `c = None` и добавлена проверка того, что  `c`  обозначает объект `None`. Весь код стал выглядеть следующим образом:

```Python
a = 1000

c = None

print("Идентификаторы:", id(a), id(b), id(c))

print("a is b:", a is b)
print("a == c:", a == c)
print("a is c:", a is c)
print("c is None", c is None)

```

Был выполнен следующий код:

```Python
first = "python"
second = "py" + "thon"

print(first == second)
print(first is second)
```

Ожидалось, что в результате будут получены `True` и `False`, но был получен следующий результат:

```
True
True
```

Так произошло, потому что `first == second` возвращает `True` из-за того, что обе переменных ссылаются на объекты с одинаковым значением. А во втором случае `first is second` вернуло `True` из-за того, что Python не стал создавать новый объект для `second` а переиспользовал уже существующий с тем же значением в целях оптимизации.

Таким образом, можно сделать вывод, что оператор `==` следует применять, когда нам нужно проверить, совпадают ли данные внутри объектов, независимо от того, где они хранятся. А оператор `is` следует применять когда вам нужно проверить, является ли объект одним и тем же конкретным экземпляром в памяти.
### Ответы на контрольные вопросы:

1. Инструкция `b = a` не создает копию объекта. Такой вывод можно сделать потому, что `id(a)` и `id(b)` имеют одинаковое значение, т.е. обе переменных ссылаются на один объект в памяти.
2. `type()` возращает тип объекта, переданного ему в качестве аргумента, а `id()` возращает адрес в памяти объекта, переданного ему в качестве аргумента.
3. `None` принято сравнивать с помощью `is`, потому что в памяти хранится единственный объект с типом `None`. А числа и строки необходимо сравнивать с помощью `==`, потому что в памяти могут хранится сразу несколько объектов с одинаковым значением.

### Эксперимент C 


В `task_3.py` был дописан следующий код:

```Python
import math

result = 0.1 + 0.2

print(result)
print(result == 0.3)
print(result - 0.3)
print(math.isclose(result, 0.3))
```

Ожидалось что в первой строчке результата будет число `0.3`, второй - `True`, третьей - `0`, четвертой - `True`. Однако после выполнения был получен следующий результат:

```
0.30000000000000004
False
5.551115123125783e-17
True
```

Это произошло из-за того, что числа с плавающей точкой хранятся в двоичном представлении. Числа `0.1`, `0.2`, `0.3` не имеют конечного точного представления в двоичной системе, поэтому Python хранит их ближайшие приближения. Из-за этого при сложении приближённых значений получается число, которое отображается как:

```text
0.30000000000000004
```

Поэтому строгое сравнение возвращает `False`:

```python
result == 0.3
```

Разность `5.551115123125783e-17` показывает величину этой погрешности.

**Безопасное сравнение**

Для сравнения чисел с плавающей точкой с учётом подобных погрешностей следует использовать `math.isclose()`:

```python
math.isclose(a, b)
```

| `has_runs`         | `bool`      |

### Разбор арифметического выражения

Для разбора можно выбрать строку:

```python
modulus = real ** 2 + imag ** 2
```

В этой строке используются следующие элементы:

- `modulus` - имя, которому будет присвоен результат вычисления;

- `real` - имя, связанное с действительной частью;

- `imag` - имя, связанное с мнимой частью;

- `+` - оператор сложения;

- `**` - оператор возведения в степень;

- `=` - оператор присваивания;

- `2` - литерал.

Вызовы функций в данной строке отсутствуют.

### Путь выполнения программы

После создания файла `task_5.py` исходный код проходит несколько этапов выполнения.

 **Исходный файл**

Сначала существует обычный текстовый файл `task_5.py`. В нём записаны инструкции программы на языке Python.

**Разбор исходного текста**

Интерпретатор CPython считывает исходный код и анализирует его структуру.
На этом этапе проверяется синтаксис программы: правильно ли записаны инструкции, выражения, вызовы функций, присваивания и другие конструкции.

 **AST**

После разбора исходный код представляется в виде AST - абстрактного синтаксического дерева (Abstract Syntax Tree). AST отражает структуру программы. Например, инструкция:

```python
gen_duration_sec = starts * duration
```

представляется как присваивание, внутри которого находится операция умножения двух имён.

**Компиляция в байткод**

Затем AST компилируется в байткод Python.

Байткод — это набор инструкций, которые предназначены для выполнения виртуальной машиной Python.

При необходимости скомпилированный байткод может сохраняться в файлах с расширением `.pyc` внутри каталога `__pycache__`.

**Выполнение виртуальной машиной CPython**

Полученный байткод выполняется виртуальной машиной CPython.
Она последовательно выполняет инструкции программы: получает ввод пользователя, преобразует значения, выполняет арифметические операции, создаёт объекты и связывает их с именами, а затем выводит результаты.

### Преобразование результата input()

Функция `input()` всегда возвращает объект типа `str`, то есть строку.
А для выполнения арифметических операций необходимо получить числовой тип. Поэтому в программе используется:

```python
starts = int(input("Введите кол-во запусков: "))
```

В этом случае сначала `input()` получает строку, после чего `int()` преобразует её в целое число. Аналогично для вещественных чисел используется `float()`:

```python
duration = float(input("Введите длительность одного запуска: "))
```


### Ответ на контрольный вопрос
 
При повторном присваивании имя начинает ссылаться на другой объект.
И если старый объект больше не связан с другими именами и на него нет других ссылок, он в дальнейшем может быть удалён сборщиком мусора Python.

В ходе выполнения лабораторной работы были выявлены три наиболее неожиданные особенности языка Python, связанные с его внутренней архитектурой и объектной моделью:

1. **Динамическая оптимизация памяти (интернирование строк):** Неожиданным оказался результат сравнения строк `first is second` во втором задании. То, что Python автоматически склеил две константные строки на этапе компиляции и переиспользовал один и тот же объект в памяти ради экономии ресурсов, наглядно показывает скрытую оптимизацию интерпретатора.
2. **Поведение функции `bool()` для строк:** Логика работы с truthy- и falsy-значениями в Python имеет свои нюансы. Эксперимент с `bool("False")` показал, что интерпретатор оценивает исключительно заполненность строки, а не значение текста.
3. **Произвольная точность целых чисел (`int`):** В отличие от большинства низкоуровневых языков программирования, где размер чисел жестко ограничен, Python поддерживает числа произвольной длины. Результат вычисления `2 ** 1000` без переполнения буфера продемонстрировал, что Python динамически выделяет память под большие числа.
