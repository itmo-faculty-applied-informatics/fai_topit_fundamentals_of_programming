## Задание 5. Информационная карточка вычислительного эксперимента

Создайте консольную программу `task_5.py`, объединяющую изученные конструкции.

### Входные данные

Программа должна запросить у пользователя:

- имя исследователя;
- название эксперимента;
- количество выполненных запусков — целое число;
- длительность одного запуска в секундах — вещественное число;
- действительную и мнимую части комплексного коэффициента — два вещественных числа.

Можно считать, что пользователь вводит корректные данные.

### Вычисления

Программа должна без условий и циклов вычислить:

- общую длительность всех запусков в секундах;
- общую длительность в минутах;
- комплексный коэффициент с помощью `complex()`;
- квадрат модуля коэффициента по формуле `real ** 2 + imag ** 2`;
- логическое значение `has_runs`, показывающее, является ли число запусков ненулевым, с помощью `bool()`.

```python
exp = input("Название эксперимента: ")
name = input("Имя исследователя: ")
launch = int(input("Количество выполненных запусков(целое число): "))
duration = float(input("Длительность одного запуска в секундах(вещественное число): "))
real,imag = map(float,input("Действительная и мнимая части комплексного коэффициента(два вещественных числа): ").split())

total_time=duration*launch
has_runs=bool(launch)
total_time_minutes = total_time / 60
complex_rate= complex(real,imag)
mod = real**2 + imag**2

print("========================================")
print(f"ЭКСПЕРИМЕНТ: {exp}")
print(f"Исследователь: {name}")
print(f"Запуски: {launch}")
print(f"Общее время: {total_time:.2f} с ({total_time_minutes:.2f} мин)")
print(f"Коэффициент: {complex_rate}")
print(f"Квадрат модуля: {mod:.2f}")
print(f"Есть выполненные запуски: {has_runs}")
print("========================================")
```

### 3. Путь программы в CPython
- Исходный файл - текст на Python в кодировке UTF-8.
- Разбор исходного текста - поток символов превращается в поток лексем, а затем проверяется грамматика языка.
- AST - по лексемам строится древовидная структура, отражающая иерархию выражений и инструкций.
- Компиляция в байткод - AST переводится в последовательность инструкций виртуальной машины.
- Выполнение виртуальной машиной CPython - интерпретатор пошагово исполняет байткод.

После присваивания нового значения уже существующему имени создаётся новый объект(если он еще не существует), имя отвязывается от старого объекта и привязывается к новому.
